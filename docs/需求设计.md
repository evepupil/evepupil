# GitHub 个人主页需求设计

## 目标

用一幅柔和细腻、细节丰富的「小狐狸像素风横版闯关」动态 SVG 建立独特个人辨识度，同时用无 emoji、去模板化的自然排版清晰展示代表项目与 TokenBoard 用量。

## 页面内容

1. **顶部像素风横版闯关动画（昼/夜自适应）**：基于头像形象绘制小狐狸角色，在充满计算机、编程与 AI 彩蛋的横版关卡中完成 14 秒循环闯关，最终走入挂有「功亦唐捐」牌匾的小屋。
2. **平实导语与前置入口**：自然句式介绍个人方向与常用语言（`TypeScript`、`Go`、`Rust`、`Cloudflare`），紧接 `chaosyn.com`、`Blog`、`Zhihu`、`TokenBoard` 链接。
3. **2×2 项目矩阵（`Projects`）**：对称展示 `NextDevTpl`、`CloudMind`、`SMem`、`DeverDesk`，不堆砌第三方徽章。
4. **单卡收尾（`Token Usage`）**：底部仅保留一张 `520px` 原生尺寸的 `TokenBoard` 卡片并链回仓库。
