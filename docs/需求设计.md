# GitHub 个人主页需求设计

## 目标

让首次访问 `evepupil` GitHub 主页的人，在首屏内记住开发者身份，并能继续了解当前方向、代表项目和外部内容。

## 目标访客

- 关注 AI 辅助开发、开发工具和开源项目的开发者。
- 可能使用项目或参与合作的访客。

## 页面内容

1. 顶部使用淡蓝色波浪横幅，展示 `evepupil` 和 `Independent Developer | AI Systems & Developer Tools`。
2. 用短段落说明个人定位和当前关注方向。
3. 展示与当前工作相符的技术栈。
4. 精选项目固定为 NextDevTpl、CloudMind 和 CCSM。
5. 保留 GitHub 活动、AI 使用情况以及个人网站、博客、知乎入口。

## 范围边界

- 参考 `epicsagas/epicsagas` 的信息层级、章节节奏和横幅形式。
- 所有项目介绍和数据必须来自公开仓库或现有公开服务。
- 页面保持英文主内容。
- 不加入奖杯墙、连续签到、活动图和其他信息价值较低或容易失效的装饰数据。

## 验收标准

- GitHub 能正常渲染全部 Markdown 和 HTML。
- 首屏身份清楚，三个项目均有有效入口。
- 淡蓝色横幅、项目徽章和正文形成统一视觉。
- 非关键第三方图片失效时，文字内容仍能完整表达主页信息。
