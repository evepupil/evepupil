# GitHub 个人主页需求设计

## 目标

将 `evepupil` GitHub 主页升级为与 `https://smem.chaosyn.com` 一脉相承的「瑞士网格 × 包豪斯几何像素海报」视觉体系，在保持柔和不闪烁的前提下，让整页（Hero、导航、2×2 项目卡片、TokenBoard 数据区）具备高度统一的平面设计感。

## 页面内容

1. **分栏像素海报 Hero**：左侧展示 9 行粗体像素大字 `EVEPUPIL`、技术栈与 `$` 终端栏；右侧在粉紫 `+` 像素编织底纹上居中展示头像小狐狸的几何像素肖像（每 5.2 秒平静眨眼一次）；底部四栏展示 `04 / 66 / 91B / MCP` 像素指标。
2. **直角方框入口栏**：前置 `chaosyn.com`、`blog.chaosyn.com`、`smem.chaosyn.com`、`@evepupil` 快捷入口。
3. **2×2 包豪斯像素编织项目海报卡**：以四张独立可点击的双主题定制 SVG 海报卡展示 `NextDevTpl`、`CloudMind`、`SMem`、`DeverDesk`，下方附产品官网与配套开源工具直达链接。
4. **单卡遥测收尾**：底部仅保留一张 `520px` 原生清晰尺寸的 `TokenBoard` 卡片。
