# GitHub 个人主页技术设计

## 技术选择

- 使用 GitHub 支持的 Markdown 与内嵌 HTML，不引入站点框架。
- 顶部和底部波浪图由 Capsule Render 生成。
- 技术栈图标由 Skill Icons 提供。
- 项目星标、主要语言和最新版本由 Shields.io 实时读取 GitHub 公共数据。
- GitHub 活动沿用 GitHub Profile Summary Cards，并针对明暗主题分别加载。
- AI 使用情况沿用公开 TokenBoard 图片。

## 页面结构

`README.md` 按个人介绍、当前方向、技术栈、精选项目、GitHub 活动、AI 使用和外部入口依次组织。精选项目使用 GitHub 支持的 HTML 表格：首行两列，CCSM 在第二行横跨两列。

## 工程约束

- 文案保持英文，设计与维护文档使用中文。
- README 中不写入需要手工维护的星标数或版本号。
- 核心信息必须以文本存在，不能只放在图片中。
- `.gitattributes` 固定文本文件使用 LF，避免 Windows 环境产生整仓换行变化。

## 验证方式

- 检查 Markdown 链接和图片地址。
- 使用 GitHub API 核实三个项目及最新版本。
- 检查图片真实加载尺寸，排除坏图。
- 在 GitHub 实际个人资料页复核首屏与各章节呈现。
