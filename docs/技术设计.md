# GitHub 个人主页技术设计

## 技术实现

- **3 倍整数像素网格（`282×96` -> `846×288`）**：配合 `shape-rendering="crispEdges"` 与同行游程编码（RLE `<path>`）保证每个像素边缘锐利且体积紧凑。
- **纯原生 SVG SMIL 帧与路径动画**：无需任何 JS，利用 `calcMode="discrete"` 实现小狐狸四帧跑步、跳跃姿态、旋转金币、爬行 `BUG` 甲虫、冒热气咖啡、飘落樱花、闪烁服务器指示灯、探头小机器人与容器小鲸鱼的逐帧动画，并与 `[>_]` 砖块顶撞弹跳、终点升旗烟花精确同步。
- **零装饰负担排版**：正文与标题完全移除 emoji、全大写口号及外部 Shields 徽章依赖，底部仅保留一张 `TokenBoard` 实时卡片。
