# GitHub 个人主页技术设计

## 技术实现

- **同源 9 行粗体像素字形与正交像素编织**：复用 `smem.chaosyn.com` 的 9 行粗体像素字库比例与四种正交几何编织纹理（`plus`、`cross`、`tartan`、`basket`），配合 `0px` 直角与 `1px` 实线网格建立统一平面语言。
- **克制低频动效**：移除高频闪烁动画，仅保留小狐狸肖像 5.2 秒一次的逐帧眨眼与终端块状光标 1.4 秒慢闪，并内置 `@media (prefers-reduced-motion: reduce)` 降级保护。
- **双主题完整适配**：全部 22 张仓库自制 SVG 均通过严格 XML 校验，并提供独立的 Light（暖白纸张底）与 Dark（深灰黑底）配色。
