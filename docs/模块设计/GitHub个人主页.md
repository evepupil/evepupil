# GitHub 个人主页模块

- **模块定位**：展示开发者身份、当前方向、代表项目和外部入口。
- **对应代码**：[`README.md`](../../README.md)、[`PRODUCT.md`](../../PRODUCT.md)、[`DESIGN.md`](../../DESIGN.md)、[`.github/workflows/snake.yml`](../../.github/workflows/snake.yml)
- **所属 M 里程碑**：[M0 GitHub 个人主页改版](../roadmap.md#m0)
- **当前状态**：已完成
- **最近更新时间**：2026-09-01

## 职责与边界

本模块负责 GitHub 个人资料页的内容和视觉组织。GitHub 平台负责正文排版与响应式渲染，外部公开图片服务负责横幅、图标、徽章和活动图。模块不运行前端脚本，也不保存访客数据。

## 结构与数据流

README 按身份、方向、能力、作品、证据和外部连接排列。GitHub 渲染正文时请求外部图片；项目描述和链接直接来自 README，实时数据由图片服务读取 GitHub 公共数据后生成。

## 关键决策

- 使用淡蓝色波浪横幅作为首屏记忆点。
- 正文沿用 GitHub 原生字体，通过二级标题、短段落和章节留白形成层级。
- 精选项目固定为 NextDevTpl、CloudMind 和 CCSM。
- 三个项目使用 GitHub 原生 HTML 表格；首行两个等宽项目，第二行 CCSM 横跨两列，边框和隔行底色由 GitHub 提供。
- 保留一张 GitHub 活动图和一张 AI 使用图，控制第三方图片数量。

## 当前实现

- 顶部横幅展示开发者名字和确认后的英文身份文案。
- About 与 Current Focus 说明工作方向。
- 技术栈用两行图标展示。
- 每个精选项目单元格包含独立标题、简介、星标、主要语言和最新版本入口。
- 页面末尾提供个人网站、博客和知乎入口，并以浅色波浪收尾。

## 验证方式

1. 检查所有本地 Markdown 链接。
2. 请求全部外部图片并确认返回成功且有有效尺寸。
3. 在 GitHub 个人资料页查看首屏、项目表格和明暗主题图片。
4. 运行 `git diff --check`，确认没有格式和换行问题。

已完成验证：GitHub Markdown 渲染接口返回正常，全部 17 张图片在公开页面具有有效尺寸，Edge 桌面与 390 像素窄屏长截图通过人工检查，Impeccable 机械检测无问题。双列表格在桌面端呈现等宽卡片和 GitHub 原生隔行底色；窄屏端保持两列并压缩或横向滚动，这是用户确认接受的目标项目原生行为。

## 待扩展项

- 现有贡献动画工作流继续保留，是否重新展示由后续需求决定。
