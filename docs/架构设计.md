# GitHub 个人主页架构设计

## 分层

1. **视觉叙事层**：仓库内 `assets/fox-stage-light.svg` 与 `assets/fox-stage-dark.svg` 通过 `<picture>` 按系统明暗主题自动切换昼夜像素关卡动画。
2. **身份与导航层**：自然大小写英文导语 + 前置外部站点文字入口。
3. **代表作品层**：GitHub 原生 HTML `2×2` 顶对齐表格展示四个主力开源项目（`NextDevTpl`、`CloudMind`、`SMem`、`DeverDesk`）及同系列工具索引。
4. **工程实证层**：底部单张 `TokenBoard` 实时统计 SVG，点击直达开源仓库。
