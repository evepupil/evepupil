# GitHub 个人主页架构设计

## 系统概览

个人主页由仓库根目录的 `README.md` 驱动，GitHub 负责渲染。外部公开图片服务只补充视觉和实时数据，主页的身份、方向和项目介绍由仓库内文本长期保存。

## 分层

1. **身份层**：顶部横幅和个人介绍回答“是谁、关注什么”。
2. **能力层**：当前方向与技术栈回答“能做什么”。
3. **作品层**：三个精选项目提供真实成果和继续访问的入口。
4. **证据层**：GitHub 活动和 AI 使用情况展示持续投入。
5. **连接层**：个人网站、博客和知乎承接后续访问。

## 数据流

GitHub 读取仓库 README 后生成页面；Capsule Render、Skill Icons、Shields.io、GitHub Profile Summary Cards 和 TokenBoard 根据公开参数返回图片。任何补充图片加载失败时，GitHub 仍会保留图片替代文字与正文内容。

## 维护边界

- 个人定位和项目选择由 README 手工维护。
- 星标、主要语言、版本和活动数据由公开服务实时生成。
- 页面不保存访问者数据，也不执行脚本。

详细实现见 [GitHub 个人主页模块](模块设计/GitHub个人主页.md)。
