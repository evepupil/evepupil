# GitHub 个人主页架构设计

## 分层

1. **海报身份层**：`assets/hero-light.svg` 与 `assets/hero-dark.svg` 通过 `<picture>` 双主题展示 `EVEPUPIL` 9 行像素主视觉、小狐狸像素肖像与四栏核心指标。
2. **直达导航层**：`assets/btn-*.svg` 提供 `0px` 直角方框站点入口。
3. **作品海报矩阵层**：`assets/card-{nextdevtpl,cloudmind,smem,deverdesk}-{light,dark}.svg` 以 `49%` 双列并排组成无原生表格灰框干扰的 `2×2` 海报矩阵，点击直达对应仓库，下方文字行直达在线官网。
4. **遥测实证层**：`assets/sec-tokens-*.svg` 分隔条 + 原生比例 `TokenBoard` 实时统计 SVG。
